# Quiz game app

An interactive multiple-choice quiz game focused on simple general knowledge about India.

## Features

- India-focused general knowledge questions
- Single-choice, multiple-choice, and fill-in-the-blank questions
- 30-second timer for every question
- Automatic timeout handling
- Different accent colors for each question
- Final scoreboard with attempted, correct, and wrong answers
- Responsive layout for desktop and mobile screens

## Run Locally

Open `index.html` directly in a browser, or serve the folder with a local web server.

Example with Python:

```bash
python -m http.server 8080
```

Then visit `http://localhost:8080`.

## Files

- `index.html` - quiz page structure
- `style.css` - responsive visual design
- `script.js` - questions, timer, interactions, and scoring
